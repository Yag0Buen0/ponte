# Fase 1 — Setup com ferramentas prontas · Plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Controlar o celular Android pelo PC (desktop e navegador) e o PC pelo celular, na rede local e de fora de casa, usando só ferramentas prontas.

**Architecture:** scrcpy + ADB por Wi-Fi para PC→celular, com um atalho `.bat` que acha o celular via mDNS. ws-scrcpy dá a mesma coisa no navegador. RDP nativo do Windows 11 Pro + app "Windows App" para celular→PC. Tailscale liga tudo de fora de casa sem abrir portas.

**Tech Stack:** winget, scrcpy (inclui adb), ws-scrcpy (Node), Remote Desktop (RDP), Tailscale, PowerShell 5.1.

## Global Constraints

- PC: Windows 11, Node 24+, winget disponível. Nada disso instalado ainda: adb, scrcpy, tailscale, ffmpeg. RDP desligado (`fDenyTSConnections = 1`).
- Celular: Android atual (≥ 11) — "Depuração por Wi-Fi" disponível.
- Repo: git local (não mexer na config global do git).
- Nada exposto direto na internet: acesso remoto só via Tailscale.
- Scripts `.ps1` sem acentos nas strings (PowerShell 5.1 lê UTF-8 sem BOM como ANSI).
- Passos marcados **[Yago]** são feitos pelo Yago (no celular, em contas ou em Configurações do Windows); o agente não executa esses.

### Task 3: Atalho `conectar-celular`

**Files:**
- Create: `fase1/conectar-celular.ps1`
- Create: `fase1/conectar-celular.bat`

**Interfaces:**
- Consumes: `adb`, `scrcpy`; celular pareado (Task 2).
- Produces: duplo clique em `fase1\conectar-celular.bat` abre o scrcpy conectado ao celular.

- [ ] **Step 1: Criar `fase1/conectar-celular.ps1`**

```powershell
# Conecta o celular via ADB por Wi-Fi (descoberta mDNS) e abre o scrcpy.
$ErrorActionPreference = 'Stop'

function Get-AdbDevices {
    adb devices | Select-Object -Skip 1 |
        Where-Object { $_ -match "`tdevice$" } |
        ForEach-Object { ($_ -split "`t")[0] }
}

function Find-CelularNaRede {
    adb mdns services |
        Where-Object { $_ -match '_adb-tls-connect\._tcp' } |
        ForEach-Object { if ($_ -match '(\d{1,3}(\.\d{1,3}){3}:\d+)') { $Matches[1] } } |
        Select-Object -First 1
}

adb start-server | Out-Null
Start-Sleep -Seconds 2   # da tempo do adb reconectar sozinho via mDNS
$devices = @(Get-AdbDevices)

if ($devices.Count -eq 0) {
    Write-Host 'Procurando o celular na rede...'
    $alvo = Find-CelularNaRede
    if (-not $alvo) {
        throw 'Celular nao encontrado. Confira: mesma rede Wi-Fi e "Depuracao por Wi-Fi" ligada.'
    }
    adb connect $alvo | Out-Host
    $devices = @(Get-AdbDevices)
}

if ($devices.Count -eq 0) { throw 'Nao consegui conectar ao celular.' }

Write-Host "Conectado: $($devices[0])"
scrcpy -s $devices[0] --no-audio --turn-screen-off
```


```markdown
# Ponte

## Fase 1 — uso diário (ferramentas prontas)

### Controlar o celular pelo PC
- Duplo clique em `fase1\conectar-celular.bat` (celular na mesma rede, "Depuração por Wi-Fi" ligada).
- Primeira vez num PC novo: parear com `adb pair <IP>:<porta> <codigo>` (Opções do desenvolvedor → Depuração por Wi-Fi → Parear com código).

### Pelo navegador
- `fase1\iniciar-web.bat` → `http://localhost:8000`.
- De fora de casa: `tailscale serve --bg 8000` → `https://<pc>.<tailnet>.ts.net` (só aparelhos da sua tailnet).

### Controlar o PC pelo celular
- App **Windows App** → PC pelo IP local ou pelo IP `100.x` do Tailscale. Usuário e senha da conta do Windows.

### Limitações
- Depuração por Wi-Fi exige o celular em Wi-Fi (não funciona em dados móveis).
- Pareamento por QR code chega na Fase 2.
```
